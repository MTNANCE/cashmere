## Setup
 - Install Docker & compose plugin
 - Run `docker compose up -d` to start Pocketbase and Next.js app
 - Run `docker compose logs pocketbase`. There will be a link that you can access to create a superadmin. Remember to switch out 0.0.0.0 with 127.0.0.1.
 - App will be running on http://127.0.0.1:3000 and Pocketbase on http://127.0.0.1:8119
